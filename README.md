# MyVault – คลังลิงก์และข้อมูลส่วนตัว

แอปมือถือ (PWA) สำหรับเก็บลิงก์เว็บไซต์และข้อมูลต่าง ๆ ไว้ใช้เอง
ข้อมูลทั้งหมดเก็บในเครื่องมือถือเท่านั้น ไม่ส่งขึ้นเซิร์ฟเวอร์

## ความสามารถ
- เก็บ **ลิงก์เว็บ** (แตะเพื่อเปิด, ดึงไอคอนเว็บให้อัตโนมัติ, ตั้งชื่อให้จากลิงก์)
- เก็บ **ข้อมูล/โน้ต** เช่น เลขบัญชี ที่อยู่ รหัส Wi-Fi — ซ่อนเนื้อหาแบบเบลอได้
- แบ่ง **หมวดหมู่**, **ปักหมุด** ไว้หน้าแรก, รายการ **ใช้บ่อย**, **ค้นหา**
- คัดลอก / แชร์ ได้ในแตะเดียว
- **ล็อกด้วย PIN 4 หลัก** (ล็อกอีกครั้งเมื่อออกจากแอปเกิน 1 นาที)
- **สำรอง / นำเข้า** ข้อมูลเป็นไฟล์ .json
- ใช้งานได้แม้ไม่มีอินเทอร์เน็ต, รองรับโหมดมืด

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด |
| `manifest.webmanifest` | ข้อมูลสำหรับติดตั้งลงมือถือ (ชื่อ, ไอคอน, สี) |
| `sw.js` | ทำให้เปิดได้แบบออฟไลน์ |
| `icons/` | ไอคอนแอป |

## ลองบนคอมพิวเตอร์
```powershell
python -m http.server 8080
```
แล้วเปิด http://localhost:8080

## ติดตั้งลงมือถือ
การติดตั้งเป็นแอปต้องเปิดผ่าน **https** จึงต้องเอาโฟลเดอร์นี้ขึ้นโฮสต์ฟรีก่อน (เลือกอย่างใดอย่างหนึ่ง)

**วิธีที่ง่ายที่สุด – Netlify Drop**
1. เข้า https://app.netlify.com/drop
2. ลากโฟลเดอร์ `version_1` ทั้งโฟลเดอร์ไปวาง
3. จะได้ลิงก์ `https://xxxx.netlify.app` → เปิดลิงก์นั้นในมือถือ

**หรือ GitHub Pages** – สร้าง repo, อัปโหลดไฟล์ทั้งหมด, เปิด Settings → Pages

จากนั้นบนมือถือ:
- **iPhone (Safari):** ปุ่มแชร์ → “เพิ่มไปยังหน้าจอโฮม”
- **Android (Chrome):** เมนู ⋮ → “ติดตั้งแอป” / “เพิ่มลงในหน้าจอหลัก”

> หมายเหตุ: ลิงก์โฮสต์ไม่มีข้อมูลส่วนตัวของคุณอยู่ในนั้น (ข้อมูลอยู่ในมือถือแต่ละเครื่อง)
> แต่ถ้าลบแอป/ล้างข้อมูลเบราว์เซอร์ ข้อมูลจะหาย — **กดสำรองข้อมูลเป็นระยะ**
> PIN เป็นการกันคนข้าง ๆ เปิดดู ไม่ใช่การเข้ารหัส อย่าเก็บรหัสผ่านสำคัญไว้ในแอปนี้
